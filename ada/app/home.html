Run sheet

  1. Start with make start. Stop with make stop.
  2. Open the stage and presenter in the same browser. Load each step with L.
  3. Use Storm, then run the evaluations with E. Expected scores are 0, 2, 3, 5 and finally 6 of 6.
  4. For chat, configure an OpenAI-compatible endpoint in .env.ada. Simulation and evaluations need no credentials.
  5. Step loading resets runtime state while preserving source edits. Ada exercises live in ada/prompts/.

The original TypeScript sources and presentation content remain a reference. This Ada adaptation uses the local protocol libraries and local Markdown memory. See README.md for configuration and migration details.
